PREGUNTA 0386 - answers incorrect
----------------------------------
Mi solución corre sin errores y sigue exactamente la lógica del enunciado.
El problema es que el generador instancia el modelo en la línea:

    model = TheilSenRegressor()  # línea 54 del generador

sin fijar un random_state. TheilSenRegressor usa submuestreo interno no
determinista, por lo que cada ejecución produce un resultado diferente aunque
reciba los mismos datos. El evaluador primero corre el generador para obtener
el expected_val, y luego corre mi función. Como son dos ejecuciones separadas
del mismo modelo sin semilla fija, los valores nunca coinciden exactamente,
aunque ambos son correctos. Mi solución usa la misma lógica que el generador:
train_test_split con random_state=42 y TheilSenRegressor() sin random_state,
tal como indica el enunciado.


PREGUNTA 0639 - answer with run error
---------------------------------------
Mi solución corre sin errores y el ranking que produce es correcto.
El problema está en la función compare_outputs del evaluador, no en mi código.
 
El generador devuelve el valor esperado como un np.ndarray de strings:
 
    output_data = np.array(X.columns[orden], dtype=str)
 
La rama del evaluador que maneja np.ndarray usa np.allclose() para comparar
los valores. Esa función asume que los arrays contienen números — cuando
encuentra strings, numpy intenta promoverlos a float y lanza el error:
 
    DTypePromotionError: The DType <class 'numpy.dtypes.StrDType'> could not
    be promoted by <class 'numpy.dtypes._PyFloatDType'>
 
La solución es añadir una verificación del dtype antes de llamar a np.allclose,
y usar np.array_equal cuando el array contiene strings:
 
    if expected.dtype.kind in ('U', 'S', 'O'):  # unicode, bytes u object
        if not np.array_equal(expected, actual_arr):
            return False, "Array contents do not match"
        return True, ""
 
Este bug afecta a cualquier pregunta cuyo generador devuelva un array de
strings (rankings, listas de nombres, etiquetas). La lógica de las soluciones
puede ser correcta pero aparecerán como run errors en lugar de evaluarse.
